IntegrationLab — plain JavaScript proof no Wisej.NET on this page: three files, one <input>, one plugin

1 · The vendor sample, isolated $(input).vendorKnob()

An <input class="knob"> is created inside div.knob-host, then the plugin enhances it in place.

–waiting for the first knobchange…

Drag the dial or use the mouse wheel: every change dispatches the vendor event knobchange on the <input>.

2 · Load-order checks (run when this page loaded)

Where the vendor keeps its instance: $(input).data("vendorKnob"). The InitScript copies that reference to this.instance so Wisej.NET code can find it.

Wrong load order — what you would see

Swap the first and third tags in the <head> of this file so the plugin runs before the library:

<!-- wrong: plugin first -->
<script src="../vendor-knob.js"></script>
<link rel="stylesheet" href="../vendor-knob.css" />
<script src="../jquery-lite.js"></script>

Then reload. The knob never appears (the raw dashed <input> stays visible) and the console shows, at load time, before any code of yours runs:

Uncaught ReferenceError: jQuery is not defined — vendor-knob.js must be loaded after jQuery.
    at vendor-knob.js:19

Later, $(input).vendorKnob(...) fails too: $.fn.vendorKnob was never registered, so TypeError: $(...).vendorKnob is not a function. The first error names an undefined symbol from the vendor library, not anything you wrote — that is the signature of a load-order bug. In Wisej.NET the same thing happens when Packages lists the plugin before jQuery.

3a · Callback wired the BROKEN way

A fake widget object stands in for the Wisej.NET wrapper. Its method is called through this inside the vendor callback — but there this is the <input> that dispatched the event.

fakeWidget.wireBroken = function () {
  $(input).on("knobchange", function (e) {
    // ✕ "this" is the <input> here, not fakeWidget
    this.fireWidgetEvent("valueChanged", { value: e.detail.value });
  });
};
not wired

3b · Callback wired the FIXED way var me = this

Capture the widget in a local variable before the callback. Only a captured reference survives into a callback that the vendor invokes later.

fakeWidget.wireFixed = function () {
  var me = this;                       // capture the widget
  $(input).on("knobchange", function (e) {
    me.fireWidgetEvent("valueChanged", { value: e.detail.value });
  });
};
not wired
